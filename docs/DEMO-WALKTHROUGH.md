# Demo Walkthrough

1. Sign in as Developer.
2. Create a signing request.
3. Observe pre-flight policy evaluation.
4. Sign in as Security Approver and approve a request that is not your own.
5. For Production, sign in as Release Manager and complete the second approval stage.
6. Observe the simulated signing operation.
7. Open Audit/Evidence and verify the audit chain.
8. Review Dashboard and Monitoring.
9. Change an environment policy and observe versioned controls.

This demonstrates governance and control design; it is not a production signing implementation.
